# openEHR Fundamentals

## What openEHR solves
openEHR separates clinical knowledge from software so clinical models can evolve without rewriting application code.

## Reference Model (RM)
The Reference Model defines the stable building blocks of an EHR:
- COMPOSITION (clinical document)
- OBSERVATION (clinical measurement)
- data structures (history/events/items)

## Archetypes
Archetypes define clinical concepts like:
- blood pressure
- pulse
They provide structured, reusable clinical definitions.

## Templates
Templates combine multiple archetypes into a usable form for data entry and storage.
This project uses a Vital Signs template.

## CKM & Discourse
- CKM hosts archetypes/templates
- Discourse supports collaboration and governance
